## 📊 关键指标说明

### 1. 记忆命中率

**定义**：用户提问时能找到相关记忆的比例

```
记忆命中率 = 找到相关记忆的提问数 / 总提问数
```

**优秀值**：> 60%  
**需优化**：< 20%

**如何提高**：
- 存储更多内容（降低存储阈值）
- 降低检索相似度阈值
- 改进存储策略

### 2. 记忆有用率

**定义**：检索到的记忆中高度相关的比例

```
记忆有用率 = 高度相关的检索结果数 / 总检索结果数
```

**优秀值**：> 70%  
**需优化**：< 30%

**如何提高**：
- 提高存储质量（只存储关键信息）
- 优化重要性计算
- 提高检索相似度阈值

### 3. 平均记忆重要性

**定义**：所有记忆的平均重要性分数

**优秀值**：0.7 - 0.9  
**需优化**：< 0.5

**如何提高**：
- 改进重要性计算算法
- 添加更多评估因素
- 定期清理低质量记忆

## 🔧 自定义与优化

### 调整存储策略

编辑 `tests/test_memory_with_conversation.py`：

```python
def should_store_as_memory(self, content: str, role: str) -> bool:
    """自定义存储条件"""
    if role == 'user':
        # 用户问题：根据长度和关键词
        has_question = any(q in content for q in ['如何', '什么', '为什么', '怎么'])
        return len(content) > 10 and has_question
    
    elif role == 'assistant':
        # 助手回答：包含知识性内容
        return len(content) > 50 and ('方法' in content or '步骤' in content)
```

### 调整重要性计算

```python
def calculate_memory_importance(self, content: str, role: str) -> float:
    """自定义重要性计算"""
    importance = 0.5
    
    # 根据内容长度
    if len(content) > 200:
        importance += 0.3
    
    # 根据关键词
    if '重要' in content or '核心' in content:
        importance += 0.2
    
    # 根据角色
    if role == 'user':
        importance += 0.1
    
    return min(1.0, importance)
```

### 调整检索阈值

```python
def retrieve_relevant_memories(self, query: str, top_k: int = 3):
    """自定义检索策略"""
    results = self.store.search(query, top_k=top_k)
    
    # 调整相似度阈值
    threshold = 0.4  # 降低到 0.4（默认 0.5）
    relevant = [r for r in results if r['similarity'] > threshold]
    
    return relevant
```
