## 🖼️ **界面功能说明**

### 顶部状态栏
- **API状态**: 显示当前连接的API服务器和模型
- **记忆状态**: 显示记忆服务是否启用

### 控制按钮
1. **切换API**: 
   - 点击打开API选择对话框
   - 显示所有服务的检测结果
   - 选择需要的API服务
   - 点击"确定"确认切换

2. **记忆管理**:
   - 点击打开记忆管理对话框
   - 三个标签页:
     * **存储记忆**: 输入并存储新记忆
     * **检索记忆**: 搜索相关记忆
     * **记忆统计**: 查看服务统计信息

3. **清空**: 清空聊天历史

### 聊天区域
- 显示对话历史
- 彩色消息标记:
  * 蓝色: 用户消息
  * 绿色: 助手消息
  * 红色: 系统消息
  * 橙色: 记忆上下文

### 输入区域
- 多行文本输入
- **Ctrl+Enter**: 快速发送
- **发送按钮**: 点击发送

## 🔧 **功能演示**

### API切换流程
1. 点击"切换API"按钮
2. 查看服务检测结果:
   - ● 绿色圆点 = 服务运行中
   - ○ 红色圆点 = 服务未运行
3. 选择一个可用的API服务
4. 点击"确定"按钮
5. 系统显示切换成功消息

### 记忆管理流程

#### 存储记忆
1. 点击"记忆管理"按钮
2. 在"存储记忆"标签页输入内容
3. 点击"存储"按钮
4. 收到成功确认

#### 检索记忆
1. 点击"记忆管理"按钮
2. 切换到"检索记忆"标签页
3. 输入查询关键词
4. 点击"检索"按钮
5. 查看匹配结果和相似度分数

#### 查看统计
1. 点击"记忆管理"按钮
2. 切换到"记忆统计"标签页
3. 查看服务信息和功能特性

### 智能对话流程
1. 在输入框输入消息
2. 按Ctrl+Enter或点击"发送"
3. 系统自动检索相关记忆
4. 显示记忆上下文（橙色）
5. 发送到API服务器
6. 显示助手回复（绿色）
7. 自动存储对话到记忆

## 🔍 **故障排除**

### 如果API切换对话框不显示
1. 检查是否有服务在运行
2. 查看顶部状态栏的API状态

### 如果记忆功能不可用
1. 检查记忆服务器是否运行: `python run_memory_api.py`
2. 查看顶部状态栏的记忆状态

### 如果对话无响应
1. 检查是否已选择可用的API服务
2. 使用"切换API"按钮切换到运行中的服务
