# 悬浮窗口检索测试指南

## 📖 简介

这份指南将教你如何使用**悬浮窗口UI**来测试Memory Tool的检索功能，使用ChatGPT历史记录作为测试数据。

## 🎯 测试流程

### 方法一：一键启动（推荐）⭐

最简单的方式，一个脚本搞定所有步骤：

```bash
# Windows用户
tools\test_with_ui.bat

# 或直接双击运行
```

这个脚本会自动：
1. ✅ 导入ChatGPT历史记录到记忆系统
2. ✅ 启动记忆API服务器（后台运行）
3. ✅ 启动悬浮窗口UI
4. ✅ 准备好进行检索测试

### 方法二：手动步骤

如果你想分步骤操作，可以按照以下步骤：

#### 步骤1: 导入历史记录

```bash
# 导入conversations.json
python tests/import_chatgpt_history.py conversations.json

# 或导入其他JSON文件
python tests/import_chatgpt_history.py chatgpt_export.json
```

#### 步骤2: 启动记忆API服务器

```bash
python run_memory_api.py
```

保持这个窗口运行，记忆服务器会在 `http://localhost:8000` 上运行。

#### 步骤3: 启动悬浮窗口

打开新的命令行窗口：

```bash
python src/advanced_floating_ui.py

# 或使用批处理脚本
start_advanced_ui.bat
```

## 🎮 在悬浮窗口中测试检索

### 1. 打开记忆管理

启动悬浮窗口后：
- 点击界面上的 **"记忆管理"** 按钮
- 确保右上角显示 "记忆: 已启用" （绿色）

### 2. 进行检索测试

在记忆管理对话框中：

1. **切换到"检索记忆"标签**

2. **输入查询关键词**
   ```
   建议测试查询：
   - Python编程
   - 机器学习算法
   - 数据分析
   - 项目管理
   - Web开发
   - 深度学习
   - 等等...（根据你的ChatGPT对话内容）
   ```

3. **点击"检索"按钮**

4. **查看结果**
   - 系统会显示最相关的记忆
   - 每条记忆都有相似度分数 `[0.xxx]`
   - 分数越高表示越相关

### 3. 查看统计信息

切换到"记忆统计"标签：
- 查看记忆服务的状态
- 查看API端点信息
- 点击"刷新统计"更新信息

### 4. 存储新记忆

切换到"存储记忆"标签：
- 输入新的记忆内容
- 点击"存储"保存
- 这些新记忆会与导入的历史记录一起被检索

## 🔍 高级测试技巧

### 1. 对比不同查询的效果

尝试相似但不同的查询，观察结果差异：
```
查询1: "机器学习"
查询2: "深度学习算法"
查询3: "神经网络训练"
```

### 2. 测试相似度阈值

观察不同相似度分数的记忆质量：
- `> 0.8`: 高度相关
- `0.6 - 0.8`: 中度相关
- `< 0.6`: 低度相关

### 3. 测试长查询 vs 短查询

```
短查询: "Python"
长查询: "如何使用Python进行数据分析和可视化"
```

观察哪种查询方式效果更好。

### 4. 测试混合内容检索

如果你的ChatGPT历史包含多个主题：
```
- 技术类: "API设计"
- 生活类: "健康建议"
- 学习类: "学习方法"
```

验证系统能否准确区分不同主题。

## 🎨 悬浮窗口功能特性

### 界面特点
- 🎯 **置顶显示**: 始终显示在其他窗口上方
- 🎨 **深色主题**: 护眼且专业的界面
- 📍 **智能定位**: 自动显示在屏幕右侧
- 💬 **实时对话**: 支持与AI实时对话

### 记忆功能
- 🔍 **智能检索**: 基于语义的相似度搜索
- 💾 **记忆存储**: 手动添加新记忆
- 📊 **统计信息**: 查看记忆系统状态
- 🔄 **自动整合**: 对话自动使用相关记忆

### 服务切换
- 🔌 **API切换**: 在本地模型和在线API间切换
- 🚦 **状态监控**: 实时显示服务状态
- ⚙️ **灵活配置**: 支持多种模型选择

## 🚨 常见问题

### 问题1: 记忆服务显示"未启用"

**解决方法**:
```bash
# 确保记忆API服务器正在运行
python run_memory_api.py
```

### 问题2: 检索没有结果

**可能原因**:
- 历史记录未正确导入
- 查询关键词与记忆内容不匹配

**解决方法**:
```bash
# 重新导入历史记录
python tests/import_chatgpt_history.py conversations.json
```

### 问题3: 悬浮窗口无法启动

**解决方法**:
```bash
# 检查依赖
pip install tkinter requests

# 或重新安装所有依赖
pip install -r requirements.txt
```

### 问题4: 相似度分数都很低

**说明**: 这可能表示：
- 查询与记忆内容确实不太相关
- 需要更精确的查询关键词

**建议**:
- 尝试使用更具体的查询词
- 查看"记忆统计"确认记忆已正确导入

## 💡 测试建议

### 1. 先导入少量数据测试

```bash
# 使用limited参数限制导入数量
python tests/test_large_conversations.py --max-conversations 10
```

### 2. 逐步增加测试复杂度

1. 简单查询 → 复杂查询
2. 单个主题 → 多个主题
3. 少量记忆 → 大量记忆

### 3. 对比不同测试工具

- ✅ **悬浮窗口**: 可视化界面，直观友好
- ✅ **交互式测试**: 命令行界面，功能更全面
- ✅ **自动检索测试**: 批量测试，全面分析

选择最适合你的测试方式！

## 🎉 测试完成后

测试完成后，你可以：

1. **查看测试数据**
   - `memory_data.json`: 所有存储的记忆
   - `memory_test_report.json`: 测试报告（如果使用了其他测试工具）

2. **清理测试数据**（可选）
   ```bash
   # 备份当前数据
   copy memory_data.json memory_data_backup.json
   
   # 清空记忆（重新开始）
   echo [] > memory_data.json
   ```

3. **继续深入测试**
   - 尝试其他测试工具
   - 调整记忆权重
   - 测试时间衰减功能
